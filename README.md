# Product API React Frontend

React + TypeScript frontend for the Spring Boot Product API.

Features: product listing, server-side pagination, search by name/SKU, category/status/price/stock filters, sorting, create product, Axios, React Query, TypeScript and responsive UI.

Backend expected at `http://localhost:8080/api`.

## Run
npm install
npm run dev

Open the Vite URL, normally http://localhost:5173.

If the browser reports CORS errors, configure the Spring Boot API to allow http://localhost:5173.
